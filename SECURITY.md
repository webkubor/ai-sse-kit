# Security Policy

## Status

`ai-sse-kit` is pre-alpha and not yet published to npm. There is no formal supported-
version matrix yet — until a `1.0` release, treat every version as potentially
breaking and unaudited beyond what CI checks (typecheck, tests, `pnpm audit --prod`).

## Reporting a vulnerability

Please open a [GitHub issue](https://github.com/webkubor/ai-sse-kit/issues) or, for
anything sensitive, use GitHub's [private vulnerability reporting](https://github.com/webkubor/ai-sse-kit/security/advisories/new)
on this repository. There is no dedicated security contact yet — this will be
revisited before a `1.0` release.
